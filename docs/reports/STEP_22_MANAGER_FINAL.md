## 잔여 항목의 분류와 완료 근거

후속 작업카드의 테스트 절은 실기기 터치와 Idle 체감 품질을 별도 사용자 환경 항목으로 유지하도록 명시한다. 원 카드 Q01/Q04의 엔진 흐름·마우스 검증은 확보했고, 사용 가능한 실기기는 없었다. AC4의 조건표·단일 부화·저장은 엔진 회귀로 검증됐다. 따라서 아래 항목을 새로운 구현 BLOCKER로 확대하지 않되 PASS 처리하거나 삭제하지 않는다.

| 항목 | 분류 / 다음 확인 |
|---|---|
| 실제 이름 입력 → 알 10회 클릭 → 부화 전체 플레이 | 사용자 환경 미검증. 물리 알 클릭 영역 포함해 격리 저장에서 확인하고 증거 추가 |
| 모바일 실기기 터치·기기별 화면 | 별도 기기 검증. Android 지원 범위 확정·해당 기기 검증 시 반드시 재확인 |
| Idle 연속 움직임 체감·흰 배경 수용 여부 | 사용자 품질 확인. 수치/화면 배치 PASS와 구분 |
| 쓰기 시작 후 디스크 장애·부분 파일 손상 | 카드에서 제외한 기존 비원자적 저장 한계. 안정화 작업에서 별도 처리 |
| 유효 입력에 GameManager가 false를 반환하도록 하는 강제 주입 | 코드 확인, 강제 주입 미검증. 실제 읽기·구조·장면 전환·쓰기 시작 실패는 검증됨 |
