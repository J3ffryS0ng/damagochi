## 실제 코드 조사

- Game.tscn은 PetArea (360,650) 아래 EggSprite, EggTouchArea, CreatureSprite를 둔다. PetArea 전체 이동은 알 입력 영역까지 옮기므로 피해야 한다.
- game.gd의 baby Idle은 CreatureSprite.position 전체를 Tween한다. 좌우 이동과 y Idle은 제어 책임을 분리해야 한다. 현재 랜덤 이동 상태/로직은 없다.
- stage=egg/baby, MainMenu 이어하기/새 게임 확인, save_version=1 및 user://savegame.json 유지가 기준선이다. 이동에 따른 저장 확장이나 부화 규칙 변경은 요구되지 않는다.
- BUG-001/002 해결 상태 유지. BUG-003 자동 부화 요구 미정, BUG-004 저장 안정화 후속은 이번 결정이나 구현에 혼합하지 않는다.
- C:/Godot/Godot.exe --version 출력: 4.7.2.stable.official.ed1daf0bf. 엔진 버전 확인만 수행했으며 게임 기능·렌더·회귀 실행 PASS가 아니다.

## 중단 원인과 사용자 결정

STEP_PLAN의 STEP 23은 랜덤 좌우 이동과 경계·속도·대기 기록을 요구하지만 체감 이동 방식과 이미지 반전을 확정하지 않는다. 최신 사용자 지시 4절은 UX에 영향을 주는 여러 설계 선택지가 있으면 임의 결정하지 말고 중단하도록 요구한다. 그래서 제품 코드 구현 전에 M-008을 결정 대기로 기록했다. 일반 구현 오류나 환경 BLOCKER가 아니며 수정 루프를 소모하지 않는다.

공통 제안은 화면 중앙 기준 ±120px 영역 내 랜덤 목적지 이동·도착 후 대기, baby 전용, 기존 y Idle 유지다. A는 60px/초·1~3초 대기의 느긋한 이동(권장), B는 100px/초·0.5~1.5초 대기의 활발한 이동이다. 최대 폭 이동 시간은 각각 약 4초·2.4초다. 외형은 원본 방향 유지(권장) 또는 진행 방향에 맞춰 좌우 반전 중 선택한다. 모든 수치는 제안이며 승인된 요구사항으로 취급하지 않는다.

기존 프로젝트 영향: A/B 모두 game.gd·필요 시 Game.tscn의 이동 표현과 검사만 확장한다. 원본 방향은 자산 외형을 유지하고, 반전은 비대칭 특징과 배경을 함께 반전한다. 저장 형식·부화·친밀도·메뉴 정책은 유지하는 제안이다. 새 자산 제작·저장 확장·STEP 24 착수는 포함하지 않는다. 다른 이동 정책 요청 시 범위 영향을 다시 기록한다.
