## 필요한 자료

현재 이미지001~004는 유아용 PNG뿐이다. 성체용 파일/연결은 없다. 실제 외형 교체에는 각 종의 성체 정지 PNG1장씩 총4장이 필요하다. 제안 위치는 assets/images/creatures/001/creature_001_adult.png부터004/creature_004_adult.png까지다. 투명 배경·기존 방향과 비슷한 캔버스 여백 권장. 원본 크기가 달라도 수신 후 배율을 조정한다. 단계/종의 연결은 파일명으로 구분한다. 빛 효과에는 별도 이미지나 음원이 필수는 아니다.

대안: 사용자 승인 시 별도 임시 성체 SVG4종으로 기능 검증하고 완료 시 실제 이미지 교체를 안내한다. 기존 유아 원본을 덮어쓰지 않는다. STEP36~44의 임시 자산 승인을 이번 성체 외형 승인으로 확대하지 않는다.

## 함께 확정할 정책 — A 권장 묶음

- 47: 4종 공통 baby, 레벨5 이상 AND 현재 친밀도10 이상. 현재 친밀도는 레벨업 때 차감되는 기존 값이며 누적 총량이 아니다. 새 누적 필드/저장 마이그레이션 없이 조건을 결합한다. 총누적 기준을 원하면 데이터/이전 저장 보완 규격을 별도 결정해야 한다.
- 판정 시점: 정상 돌봄 보상 저장이 성공하고 행동이 끝난 후, 또는 게임 진입 시 조건을 만족하면 자동 진화. 다른 행동·부화·진화 중 중복 시작은 차단한다. 레벨업 직후의 차감된 현재 친밀도로 판정한다.
- 48: 기존 부화와 어울리는 흰 빛 약1초(0.3초 밝아짐,0.2초 유지,0.5초 사라짐), 연출 중 행동 차단. 연출의 최고 밝기에서 조건/대상 재검증 후 성체 전환·저장·이미지 갱신. 저장 시작 실패는 baby 복구/안내, 무한 자동 재시도 없음. commit 전 장면 이탈은 취소, commit 후 이탈은 저장된 성체 유지.
- 49: 종ID와 수치 유지, stage만adult로 변경하고 각 종의 성체 이미지를 표시한다. 성체도 이동·Idle·먹기·놀이·청소를 계속 사용할 수 있도록 기존 baby 전용 자격을 확장한다. 재진화는 하지 않는다.
- 카탈로그에 adult_image/adult_scale을 한 쌍의 선택 필드로 추가한다. 누락된 구정의는 기존 baby 자산으로 표시를 대체하며, 제공된 잘못된 필드는 기존 전체 카탈로그 안전 대체 정책을 적용한다. 이번 등록4종은 실제 또는 승인된 임시 성체자산을 연결한다. save_version1과 기존 ID/성장 필드 유지.

대안 영향: 현재친밀도 임계값을 낮추면 진화가 빠르고 높이면 레벨업 차감 때문에 조건 도달 시점이 달라진다. 누적친밀도는 저장 규격 변경이 필요하다. 수동 진화는 버튼/UI 설계가 추가된다. 성체 돌봄을 비활성으로 유지하면 진화 이후 육성이 멈춘다. 권장안은 현재 육성 흐름을 이어가는 최소 통합안이다.
