## 현재 상태

MASTER, STEP_PLAN, BUG_LOG, DECISION_LOG, COMMON_OPERATIONS_TEMPLATE, docs/tasks 및 docs/reports와 실제 카탈로그·GameManager·GameDataFactory·Game 코드를 조사했다. STEP 45 최종 PASS·DEV539/QA781 기록을 확인했고, step_45/qa_final_hashes.json의 제품14개와 현재 파일의 SHA256이 모두 일치했다. 선행 기능 변경 근거 없음. 기존 미커밋 변경 및 사용자 자산을 보존한다.

현재 레벨은1에서 시작하고 친밀도 목표10부터 매 레벨 ceil(이전목표×1.25)로 증가한다. 알 부화는 기존 레벨2와 시간 조건을 사용한다. 성체는 단계 메타데이터만 있고 레벨 임계값·자동 성체 진화 함수는 없다. STEP_PLAN의 미정 수치 항목도 진화 규칙을 결정 대기로 둔다. M-022는 단계 데이터만 승인했으며 STEP46 레벨 수치를 확정하지 않았다. 과거 STEP32~35 권장안 위임을 STEP46 정책 위임으로 확대 해석하지 않는다.

## 결정할 문제와 선택지

성체 진화의 공통 레벨 기준과 이번 구현의 적용 범위를 확정해야 한다.

- A 권장: 4종 공통 레벨5 이상, baby의 레벨 조건만 읽기 전용으로 판정. 실제 단계 전환은 STEP47 친밀도 조건 및 STEP48~49 효과·이미지 구현과 통합한다. 빠르게 검증 가능한 초기 기준이며, 현재 게임 동작과 저장 형식을 유지한다.
- B 다른 공통 레벨: 사용자 지정 수치 적용. 예를 들어3이면 조건 도달이 빠르고10이면 육성 기간이 길어진다. 레벨 기준이 높은 기존 baby도 조회만으로 변환하지 않는다.
- 종별 기준은 추가 수치·공용 규격 설계가 필요해 현재 권장 범위에서 제외한다. 지금 레벨만으로 즉시 성체 전환하면 후속 친밀도 조건을 우회하고 성체 전용 이미지/돌봄이 미구현인 상태가 되므로 권장하지 않는다.

원인은 구현 오류가 아닌 미정 제품 정책이다. 최초 사용자 운영 지시의 '제품 정책 결정' 중단 기준에 따라 DEV 구현을 보류한다. 작업카드 docs/tasks/STEP_46_DEV.md에 구체적 계약·AC·DEV/QA 검증 범위를 준비했으며 답변 후 DEV부터 재개할 수 있다. 새 이미지는 이번 조건 판정에 필요하지 않다.
