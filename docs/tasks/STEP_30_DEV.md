## 목표·선행

## M-015 제안 — 확정 전 구현 금지

- **A 권장:** 놀이 한 사이클 정상 완료당 친밀도+1. 밥주기와 동일한 1회 보상 단위다. 놀이1.2초는 급식1.4~3.4초보다 짧으므로 시간당 성장 속도는 같지 않다.
- **B:** 정상 완료당+3. 놀이당 성장이 빨라지고 동일+1 급식보다 보상 차이가 커진다.
- 공통: 세 번 점프가 모두 끝난 뒤 시작 당시 대상에 딱1회 지급. 시작/중간/취소·장면이탈·자격상실·대상교체는0회. 조기·중복·이전세대 완료 및 직접 입력 재진입으로 중복 지급하지 않는다. 연출 중 두 행동 차단·예약없음·추가쿨다운없음 유지.
- GameManager의 기존 레벨업/잔여 친밀도/다음 목표 규칙을 그대로 사용하고 UI갱신·즉시저장. 저장경로/필드/버전 및 managers 계약 변경 없음.
- 유효하지 않은 보상 데이터는 지급 거부, 명시적 처리/저장 실패 시 이번 친밀도·레벨·목표 변화를 메모리 복구하고 실패 안내 후 정상 조작 복귀. 자동 재지급/재시도 없음. 다음 새 사이클은 새 보상 시도다.
- 놀이 실패는 기존 안내 영역에 놀이 재시도를 설명한다. 다음 유효 놀이 시작은 이전 놀이 안내만 지우며 기존 급식 안내는 유지한다. 급식의 기존 안내·새 급식 시 안내 초기화 동작은 유지한다. 부적격 입력으로 안내를 지우지 않는다.
- 실제 쓰기 시작 거부에서 기존 파일 보존을 검증한다. 디스크 부분쓰기·원자 복구·전체 로더 개편은 기존 BUG004 후속이며 이번 메모리 복구로 보장하지 않는다.

허용: game.gd, 필요시 Game.tscn, 신규 tests/step_30 및 카드/보고/상태문서. managers·자산·기존 카드/보고/검사·COMMON_OPERATIONS_TEMPLATE 유지. M014의 STEP29 한정 놀이 데이터불변을 확정 보상으로 확장하며 연출 자체는 변경하지 않는다.
