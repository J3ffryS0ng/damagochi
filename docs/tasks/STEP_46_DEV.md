## 목표와 선행조건

STEP 45 PASS 및 검증 제품 파일 14개와 현재 파일의 해시 일치를 확인했다. egg → baby → adult 메타데이터, 사용자 이미지 4종·각25% 지급은 확정 상태다. STEP 46은 baby → adult의 레벨 조건을 구현한다. 레벨 수치는 아직 확정되지 않았으므로 아래 권장 계약은 승인 전 초안이다.

## 권장 계약 A

- 현재 4종의 공통 기준은 레벨 5 이상. baby에 대해서만 레벨 조건 충족 여부를 읽기 전용으로 조회한다.
- 이번에는 조건 판정까지만 구현한다. 조건 만족만으로 stage·이미지·저장을 변경하지 않는다. 친밀도 조건은 STEP 47, 효과·이미지 전환은 STEP 48~49에서 통합한다.
- 기준은 한 곳에서 관리하고, 기존 카탈로그·save_version1 저장 형식은 변경하지 않는다. 기존 알 부화의 레벨2·시간 조건도 유지한다.
- egg/adult/미등록 단계, 잘못된 대상·인덱스, 누락/잘못된 레벨에는 충족으로 판정하지 않는다. JSON에서 읽은 정수값의 float 표현은 허용하되 문자열·bool·음수·비정수·비유한 숫자는 거부한다.
- 기존 이미지와 각25% 지급, 돌봄·친밀도·레벨업 흐름을 보존한다. 제품 정책 추가 판단은 MANAGER로 반환한다.

대안 B: 다른 공통 레벨을 지정한다. 3은 빠른 조건 도달, 10은 더 긴 육성 기간이다. 종별 조건을 다르게 정하려면 종별 수치와 데이터 규격을 별도로 결정해야 하므로 이번 권장 범위에는 포함하지 않는다.
