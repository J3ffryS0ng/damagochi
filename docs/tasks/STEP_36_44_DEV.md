## M021 확정 정책

- data/creatures.json은 저장과 분리된 종 정의 파일. 기존 creature_id 문자열 001/002/003 그대로 사용, save_version=1/저장필드/진행수치 유지. 새 ID 체계/저장 마이그레이션 없음.
- 001은 기존 원본 PNG/방향/scale(0.2633197,0.24048276) 유지. 002/003은 자체 SVG 임시 테스트 이미지, 256×256에 서로 구분되는 모양/색·번호로 표시. 실제 이미지를 넣을 경로와 JSON 수정 방법을 문서화하고 최종 사용자에게 요청한다. 외부 이미지 불필요. assets 인덱스 임시 상태 기록.
- 공통 알은 기존 SVG/0.7scale. 이름은 테스트 캐릭터 001/002/003. 세 종 시험 희귀도 test, weight=1:1:1(각1/3). 성장/돌봄/부화 조건 공통 유지. 45단계 진화 데이터는 아직 추가하지 않는다.
- 신규 게임 생성 시 한 번 가중 추첨해 creature_id 저장. 부화/이어하기/장면 재진입/새게임 저장성공 후 장면전환 재시도는 재추첨하지 않음. 메뉴 취소는 기존 저장/ID 유지.
- 정의 구조/version/중복·빈 ID/필수값/이미지 경로/수치와 weight 검증. 가중치는 유한 0~1,000,000, 합>0. weight0 선택 제외. 무효 카탈로그는 경고와 안전한 내장001 정의로 전체 대체(부분 유효 데이터 몰래 선택하지 않음). 미등록 저장ID는 데이터/ID를 고치지 않고 표시만001 대체·경고, 재추첨/자동저장 없음. 기존 BUG004 전체 저장 검증/원자쓰기 확대하지 않음.
- 데이터에서 이미지와 종별 표시scale 연결(필드명/내부 API는 DEV 결정). 정의 조회 결과의 외부 변경이 전역 카탈로그를 오염시키지 않음. 추첨 난수는 이동/응가 난수와 분리, 시험에서는 seed 주입 가능. 데이터 오류 진단은 개발 로그로, 정상 UI에 내부구현 노출 없음.
