## 범위 제안·결정 지점

수정 예정: scenes/game/Game.tscn, scripts/game/game.gd, tests/step_24 신규 검사와 신규 DEV/QA 보고. 기존 하단 메뉴를 옮기지 않고 빈 좌측 공간에 ‘밥주기’ 버튼을 둔다. 배치는 기존 버튼 높이·스타일을 재사용하는 통상 구현이며 기존 캐릭터/알 입력과 겹치지 않도록 검증한다.

M-009 A(알 상태 표시·비활성, baby 활성) 또는 B(알 상태 숨김, baby 표시·활성) 선택 필요. 부화 연출 중·빈 데이터·미지원 stage는 입력 차단을 제안한다. DEV는 알 급식 정책을 임의 결정하지 않는다.

허용된 누름 1회는 내부 feed_requested 신호 1회로 연결한다. 현재 STEP에서는 음식·친밀도·레벨·저장 변경이나 이동 중단, 쿨다운·급식 중복 제한을 추가하지 않는다. 누름의 실제 음식/먹기 효과는 STEP 25~27이며 구현되지 않은 효과를 화면에서 성공한 것처럼 안내하지 않는다. 이것은 버튼/입력 준비 단계 완료 조건이며 전체 밥주기 기능 완료가 아니다.
